# Campusly Student Portal

A responsive, front-end-only student portal demo built with HTML, CSS, and JavaScript. It is designed to work as a static website on GitHub Pages.

## Features
- Dashboard with academic summary, daily schedule, announcements, and assignments
- Weekly class schedule
- Grades and GPA overview
- Campus announcements
- Fictional student profile
- Responsive navigation for desktop and mobile
- No backend, database, build step, or API key required

## Run locally
Open `index.html` in a modern browser. For a local web server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Create a **public** repository on GitHub (for example, `student-portal`).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your live URL will appear in the Pages section.

All student information in this project is fictional.
